# 4. Own colour scheme by default, dynamic colour opt-in

- **Status:** accepted
- **Date:** 2026-10-13

## Context
The template enabled Material You dynamic colour on Android 12+, so the app's colours came from
each user's wallpaper.

## Decision
The app uses its own light and dark Material 3 schemes (teal, seed `#006A6A`). `VoiceLabTheme`
keeps a `dynamicColor` parameter, defaulting to `false`.

## Consequences
- The app looks the same on every device, so README screenshots and test failure screenshots are
  reproducible.
- Users on Android 12+ do not get wallpaper-matched colours unless it is switched on.
- The scheme is hand-picked, not generated by Material Theme Builder; regenerate it there if
  contrast issues show up in the accessibility pass.
